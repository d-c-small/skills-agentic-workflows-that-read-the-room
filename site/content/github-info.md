## Latest GitHub Updates

### GitHub Copilot

- **Trigger Copilot automations with comments** — You can now trigger Copilot cloud agent tasks directly from issue and PR comments, making it easier to kick off automation without leaving the conversation. ([GitHub Changelog, Aug 3 2026](https://github.blog/changelog/2026-08-03-trigger-copilot-automations-with-comments))
- **Customize the reasoning level for Copilot cloud agent** — Developers can now tune how deeply the Copilot cloud agent reasons through a task, giving more control over speed vs. thoroughness. ([GitHub Changelog, Aug 3 2026](https://github.blog/changelog/2026-08-03-customize-the-reasoning-level-for-copilot-cloud-agent))
- **Kimi K3 now available in GitHub Copilot** — Another model choice added for Copilot users. ([GitHub Changelog, Aug 6 2026](https://github.blog/changelog/2026-08-06-kimi-k3-is-now-available-in-github-copilot))
- **Copilot code review effort levels are generally available** — Choose how thorough Copilot's code review should be; this feature has now graduated from preview to GA. ([GitHub Changelog, Aug 7 2026](https://github.blog/changelog/2026-08-07-copilot-code-review-effort-levels-are-generally-available))
- **Copilot impact dashboard adds ROI section** — The Copilot impact dashboard now includes a return-on-investment section to help teams quantify productivity gains. ([GitHub Changelog, Aug 7 2026](https://github.blog/changelog/2026-08-07-copilot-impact-dashboard-adds-a-return-on-investment-section))
- **Copilot usage metrics API adds agent app activity** — The API now surfaces activity from Copilot agent apps, giving admins a fuller picture of how Copilot is being used. ([GitHub Changelog, Aug 7 2026](https://github.blog/changelog/2026-08-07-copilot-usage-metrics-api-adds-agent-app-activity))
- **MCP allowlists in enterprise managed settings** — Enterprise admins can now control which MCP servers Copilot is permitted to use via an allowlist. ([GitHub Changelog, Aug 6 2026](https://github.blog/changelog/2026-08-06-mcp-allowlists-in-enterprise-managed-settings))

### Security & Supply Chain

- **Secret scanning coverage updates** — Additional secret types are now detected by GitHub secret scanning. ([GitHub Changelog, Aug 7 2026](https://github.blog/changelog/2026-08-07-secret-scanning-coverage-updates))
- **Customize code scanning default setup at scale** — Organizations can now configure code scanning default setup settings across multiple repositories from a single place. ([GitHub Changelog, Aug 4 2026](https://github.blog/changelog/2026-08-04-customize-code-scanning-default-setup-at-scale))
- **CodeQL 2.26.2 adds Swift 6.3.3 and Kotlin 2.4.10 support** — Updated language support for Swift and Kotlin in the latest CodeQL release. ([GitHub Changelog, Aug 4 2026](https://github.blog/changelog/2026-08-04-codeql-2-26-2-adds-swift-6-3-3-and-kotlin-2-4-10-support))

### Issues & Projects

- **"Relates to" issue relationship in public preview** — A new lightweight relationship type lets you link related issues without the parent/child hierarchy. Multi-select fields are now generally available. ([GitHub Changelog, Aug 7 2026](https://github.blog/changelog/2026-08-07-connecting-issues-and-multi-select-field-support))
- **Set pull request limits at the organization level** — Org admins can now cap the number of open PRs per repository at the org level. ([GitHub Changelog, Aug 6 2026](https://github.blog/changelog/2026-08-06-set-pull-request-limits-at-the-organization-level))
- **Enterprises can now install third-party GitHub Apps** — Enterprise accounts can directly install GitHub Apps, streamlining toolchain setup for large organizations. ([GitHub Changelog, Aug 7 2026](https://github.blog/changelog/2026-08-07-enterprises-can-now-install-third-party-github-apps))
